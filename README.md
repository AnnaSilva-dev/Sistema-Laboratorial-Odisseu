## Sobre o sistema:
<p align="justify">
O presente trabalho tem como objetivo desenvolver um sistema informatizado voltado para a gestão da rotina laboratorial em laboratórios de análises clínicas, 
possibilitando o cadastro de pacientes, a marcação de exames e o registro de resultados laboratoriais.
</p>

## Metodologias utilizadas
<p align="justify">
Para tanto, utilizar-se-á um Sistema de Gerenciamento de Banco de Dados Relacional (SGBDR), responsável por armazenar e organizar as informações dos pacientes e dos exames de forma estruturada e segura. 
Além disso, o sistema será desenvolvido como uma aplicação web, 
utilizando o framework Django e a linguagem de programação Python, permitindo maior acessibilidade e integração entre os diferentes componentes do sistema.

</p>

## Resultados esperados
<p align="justify">
Espera-se que a implementação do sistema contribua para a redução de processos manuais, otimizando a gestão das rotinas laboratoriais. Dessa forma, o projeto busca demonstrar a relevância do uso de
tecnologias digitais na modernização dos serviços laboratoriais, contribuindo para a melhoria da qualidade dos serviços de saúde como um todo.
</p>
